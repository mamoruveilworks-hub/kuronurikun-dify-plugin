# 個人情報黒塗りくん

**作者：** kuronurikun
**バージョン：** 0.2.0
**種類：** ツール
**ソース：** https://github.com/mamoruveilworks-hub/kuronurikun-dify-plugin

## 概要

日本語の文章から個人情報を見つけて `[PERSON_1]` のような記号に置き換え、LLMに渡す前に伏せます。LLMの回答に入った記号は、元の名前や番号に戻せます。同じ人には同じ記号が付くので、LLMは「誰が誰か」を区別したまま文章を理解できます。

**初期設定では、文章はあなたのDifyの外に出ません。** 検出と置き換えはプラグインの中で行い、kuronurikun.com には利用量を数えるための「文字数」だけを送ります。個人情報を社外に出せない会社でも使えます。設定で、文章を kuronurikun.com のAPIに送って処理する方法も選べます。

氏名（敬称・役職・項目名・よくある姓名の辞書）、住所、電話番号、メールアドレス、郵便番号、生年月日（和暦を含む）、マイナンバー、口座番号、クレジットカード番号、運転免許証番号、パスポート番号、基礎年金番号、保険証の番号など、日本の書き方に合わせて見つけます。

```text
入力：山田太郎様の電話は090-1234-5678です。
伏せた文章：[PERSON_1]様の電話は[PHONE_1]です。
元に戻した回答：山田太郎様、090-1234-5678へ本日中にお電話いたします。
```

## 設定

1. https://kuronurikun.com で、無料のAPIキー（月10万文字まで）を発行します。クレジットカードは不要です。
2. Difyのマーケットプレイスから、このプラグインをインストールします。
3. 「ツール → 個人情報黒塗りくん」を開き、APIキー（`pmk_` で始まる値）を入れて、「**文章を処理する場所**」を選びます。
   - **このDifyの中**（初期設定）：文章はDifyの外に出ません。利用量を数えるため、文字数だけを送ります。
   - **黒塗りくんAPI**：文章を `https://kuronurikun.com` に送って処理します。

バージョン 0.1.0 から使っている場合は、この設定を変えるまでAPIを使い続けます。

## 使い方

| ツール | 入力 | 出力 |
|---|---|---|
| 個人情報を伏せる（`mask_pii`） | `text`、`style`（tag / block / asterisk / redact）、`extra_entities`（任意：AGE, GENDER, COMPANY, CARD_EXPIRY） | `masked_text`、`mapping_token`、`entity_count` |
| 個人情報を元に戻す（`unmask_pii`） | `text`、`mapping_token` | `restored_text` |

### チャットフローの例

```text
開始
  → 個人情報を伏せる   （text = sys.query）
  → LLM               （ユーザーのプロンプト = 伏せる.masked_text）
  → 個人情報を元に戻す （text = LLM.text、mapping_token = 伏せる.mapping_token）
  → 回答               （元に戻す.restored_text）
```

注意：

- **伏せるのはLLMの前に。** ワークフローの順番として、LLMのブロックより前に置いてください。エージェントにツールとして渡すだけでは、ツールを呼ぶ前に元の文章がLLMに届いてしまいます。
- チャットフローでは、LLMの**会話の記憶（メモリ）をオンにしない**でください。過去の元の文章がLLMに渡ります。
- システムプロンプトで、`[PERSON_1]` などの記号を書き換えないようLLMに指示してください。
- **`mapping_token` はLLMに渡さないでください。** 元の値が入っています。「元に戻す」の入力にだけ使います。
- 「伏せる」の `json` 出力には、元の値は入っていません。
- ルールと辞書で判定しているので、珍しい名前などは見逃すことがあります。大切なデータでは、人の目での確認と組み合わせてください。

## 処理する場所の違い

| | このDifyの中（初期設定） | 黒塗りくんAPI |
|---|---|---|
| 文章の送り先 | どこにも送らない（プラグインの中で処理） | `https://kuronurikun.com`（AWS東京リージョン） |
| 送るもの | APIキーと文字数（`/v1/usage`） | APIキーと文章（`/v1/mask`、`/v1/unmask`） |
| `mapping_token` | 元の値を符号化したもの。あなたのDifyの外には出ない | 暗号化（AES-256-GCM）。発行したAPIキーでのみ使え、24時間で無効 |

どちらの場合も、Difyから `https://kuronurikun.com` にHTTPSで接続できる必要があります。

## 料金

どちらの処理場所でも、伏せた文字数で数えます（元に戻す処理は数えません）。Free：月10万文字まで無料。Lite：月980円で100万文字。Pro：月4,980円で1,000万文字。詳しくは https://kuronurikun.com/#pricing

## プライバシー

初期設定では、文章はあなたのDifyの外に出ません（送るのはAPIキーと文字数だけです）。APIを使う場合、文章はAWSの東京リージョンでメモリ上で処理し、保存もログへの記録もしません。詳しくは [PRIVACY.md](../PRIVACY.md) と https://kuronurikun.com/legal/privacy をご覧ください。
